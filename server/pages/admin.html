Stations

Clients and their radio stations
New station
Leave the login user empty for a Memoryq-run station. If the login user already exists, the station is added to that account (its password is not changed). People can also sign up and pay themselves at memoryq.com/studio.
Try the Studio (trial station)
One station any visitor can run with a shared login, shown on memoryq.com/studio and on the home page. Every 2 hours it goes back to the starting point (songs, playlists, stories, settings) and everyone trying it is signed out. The trial login cannot change its password or email, buy, see DJ logins or the live DJ password, rename the station, go live with video, chat or post.

Settings

Online payment (Stripe)
The key is in your Stripe dashboard: Developers - API keys - Secret key (start with a sk_test_ key to try it out with the card 4242 4242 4242 4242). Also open Settings - Billing - Customer portal in Stripe and press Save once, so station owners can change their card or cancel. Without a key, sign-ups wait as "not paid" and you activate them here.
Live DJ Pro - Dropbox - lets DJs pick songs from their own Dropbox in the console library.
Make the key once: dropbox.com/developers - Create app - Scoped access - Full Dropbox - any name. In the app's Settings, under "Chooser / Saver / Embedder domains", add memoryq.com. Copy the App key (not the secret) here.
Plans - what each station may use. Empty / 0 = no limit. Stations on a plan get its stream quality.
1. On the Centova server
Make an import code, then paste the command in a terminal on the Centova server (Bitvise: "New terminal console", logged in as root or with sudo). It only READS Centova and sends a copy of the accounts, playlists and songs here. Running it again sends only what is missing.
If it stops with "certificates are too old" (old CentOS), run it with INSECURE=1 in front of bash: sudo INSECURE=1 bash mq-export.sh CODE
2. What arrived
Every station gets a new live DJ port (8010-8099) and keeps its DJ password, its songs, playlists (rotation, interval, scheduled shows, immediate), time zone and listener / quality limits. Owners log in at memoryq.com/studio with the login user shown.

Old links (when the stations play well here): on the Centova server run - it switches the Centova streams off and sends everyone who opens an old link (http://old-server:port/...) to the station's Memoryq link. Old listening links
Players, Radio.garden, TuneIn and websites keep their old links: Memoryq plays the station on them. Centova links (http://old-address:PORT/stream) work once the old address is on this server (oldlinks.sh). Imported stations are added by themselves.
